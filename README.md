Стоп-лист ресторана

Одностраничное приложение для управления стоп-листом ресторана. Слева меню с поиском и фильтром по категориям, справа стоп-лист. Позицию можно отправить в стоп-лист через форму с указанием причины и вернуть обратно в меню. Данные берутся из локального menu.json, бэкенда нет.

Стек: React 18, Vite, Zustand, SCSS.

Запуск локально
bash
npm install
npm run dev

После запуска приложение откроется по адресу, который выведет Vite (http://localhost:5173).

Сборка для продакшена:

bash
npm run build
npm run preview
Принятые решения

Меню, стоп-лист, фильтры и открытая форма хранятся в одном Zustand-сторе, поэтому компоненты берут нужные данные сами. Стоп-лист сохраняется в localStorage через middleware persist, а видимый список меню не хранится отдельно, а вычисляется через useMemo из меню, стоп-листа и фильтров, чтобы исключить рассинхрон. Правила валидации вынесены в utils/validation.js отдельной функцией на каждое поле: при отправке проверяется вся форма, а при исправлении поле перепроверяется сразу.
